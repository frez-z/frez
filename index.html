How I work / 02

I like working close to the hardware.

My projects usually start with a practical question: what needs to be measured, controlled, or made easier? From there I move between the bench, CAD, and code — testing assumptions as I go.

I have worked on power monitoring, autonomous vehicles, machine vision, automotive electronics, and tolling systems. The common thread is simple: make the system understandable, then make it dependable.
